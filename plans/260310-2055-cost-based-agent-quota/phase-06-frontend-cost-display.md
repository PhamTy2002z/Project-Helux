## Implementation Steps

### 1. Regenerate API types

Run orval to pick up new `cost_*` fields on `AgentRead` and `float` type on `QuotaUsage`:
```bash
cd frontend && pnpm orval
```

### 2. Update `AgentsTable` token column

Current column shows `token_remaining_today / token_limit_today`. Update to show cost as primary:

```tsx
// If cost data available, show cost; else show tokens
const costUsed = agent.cost_used_today;
const costLimit = agent.cost_limit_today;
if (costUsed != null && costLimit != null) {
  return `$${costUsed.toFixed(2)} / $${costLimit.toFixed(2)}`;
}
// Fallback to token display (existing logic)
```

### 3. Update `QuotaSummary` resource labels

Add:
```tsx
agent_daily_cost: "Agent cost / day",
org_daily_cost: "Org cost / day",
```

Add USD formatting for cost resources:
```tsx
const formatValue = (value, resource) => {
  if (resource?.includes("cost")) return `$${value.toFixed(2)}`;
  return Intl.NumberFormat("en-US").format(value);
};
```

### 4. Update AgentsTable test fixtures

Add `cost_used_today`, `cost_limit_today`, `cost_remaining_today` to test agent fixtures.
